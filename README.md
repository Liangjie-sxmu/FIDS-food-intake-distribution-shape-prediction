# FIDS: reader reproduction release

This repository contains the **aggregate inputs and R code needed to reproduce the figures and tables supplied in `outputs/`** for the FIDS analysis.

It is intentionally a **reader-facing reproduction package**, not a complete end-to-end reanalysis archive. It does not contain individual-level dietary records and does not re-estimate usual-intake shape parameters, refit the hierarchical/LOCO models, or rerun the full PAF calculation pipeline.

## What this repository reproduces

Running `run.R` regenerates the same reader-facing files supplied under:

- `outputs/figures/`
- `outputs/tables/`

The released figures are:

- `Figure1A_consumption_probability.png`
- `Figure1B_positive_amount_shape.png`
- `Figure4_PAF_food_outcome_heatmap.png`
- `Figure_S2A_CHNS_2day_vs_3day.png`
- `Figure_S2B_CHNS_food_sensitivity.png`
- `Figure_S3_NHANES_direct_partial.png`
- `Figure_S4_NHANES_cycle_sigma.png`
- `Figure_S5_CHNS_wave_sigma.png`
- `age_consistency.png`
- `country_level_shape_evidence.png`
- `cross_country_consistency.png`
- `sex_consistency.png`
- `temporal_consistency.png`

The released tables are:

- `Figure4_PAF_food_outcome.csv`
- `LOCO_M0_M1_accuracy.csv`
- `PAF_M0_summary.csv`
- `Table_S5_LOCO_sensitivity_M0_M1.csv`
- `cross_country_consistency.csv`

No additional appendix distribution PDFs, plot-audit files, full PAF recalculation files, or model-refitting outputs are generated by the reader reproduction entry point.

## Requirements

R with the packages:

```r
install.packages(c("data.table", "ggplot2"))
```

CmdStan is **not required** for this reader reproduction package because model fitting is not rerun. The analysis that generated the stored model predictions used CmdStan 2.39.0, but those stored aggregate predictions are supplied directly here.

## Reproduce the released outputs

From R:

```r
setwd("path/to/FIDS_prediction_reader_release_final")
source("run.R")
```

or from a terminal:

```bash
Rscript run.R
```

The scripts overwrite/recreate the files under `outputs/figures/` and `outputs/tables/` using only the aggregate inputs supplied in `data/`.

## Repository contents

- `data/shape/`: aggregated survey-level consumption probability and positive-amount shape estimates used for Figure 1.
- `data/cross_country/`: aggregated country-level shape evidence.
- `data/consistency/`: aggregated sex, age, temporal, wave and cycle summaries.
- `data/prediction/primary/` and `data/prediction/sensitivity/`: saved aggregate LOCO prediction results used to calculate the reported accuracy tables. These are not individual records.
- `data/PAF/`: aggregate country-balanced PAF comparison summaries and risk parameters used for the released PAF summary and heatmap.
- `data/sensitivity/`: aggregate CHNS two-versus-three-day and NHANES recording-mode sensitivity summaries.
- `R/reproduce_results.R`: main reproduction script.
- `R/manuscript_outputs.R`: manuscript-facing figure/table generation.
- `R/plot_recording_sensitivity.R`: Supplementary Figures S2 and S3.
- `outputs/`: the frozen reader-facing figures and tables that the scripts reproduce.

## Data availability and scope

No individual-level dietary records are included. The repository contains only derived aggregate inputs needed to regenerate the released displays and summary tables.

Accordingly, this package supports **reproduction of the released figures and tables from supplied aggregate results**. It does not support reconstruction of the entire analysis from original individual-level CHNS, NHANES or FAO/WHO GIFT dietary records. Access to those source datasets remains subject to the relevant data custodians and their applicable terms.

## Statistical notes

Shape consistency is summarized using absolute log ratios of sigma estimates. LOCO accuracy uses equal weighting of left-out countries within each food. The released PAF summary uses the stored main-model (M0), country-balanced comparisons at the 99.9% exposure cap and excludes RR = 1 numerical controls from the main error summary; RR = 1 cells are displayed as numerical zero controls in the heatmap.
